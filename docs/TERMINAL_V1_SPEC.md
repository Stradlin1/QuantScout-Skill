# V1 终端版补充规范

2026-10-09 用户明确要求：“我不要可视化点击，一切交互终端完成即可。”

这条最新要求优先于原附件的模块 E、graph.html、Netron、前端依赖及浏览器验收要求。仓库保留原附件作为来源，实际实现遵循本补充规范。

- 解析、Conv2D 提取、带官方依据的 YAML、确定性检查、未知条件、节点依赖溯源继续保留。
- 输出改为 analysis.json 与 report.md；analyze 在终端展示异常摘要和代表路径。
- 提供 nodes（列出/搜索/状态过滤）、inspect（参数/规则/来源/建议）、trace（到输出的依赖）命令。
- 三个查询支持 --json，可用于管道。读取已保存结果，不重新加载权重。
- 原始节点名可能重复，内部 ID 始终可用；重名查询应明确报错而不是选错节点。
- 不生成 HTML，不依赖前端库或浏览器，不提供 Netron 启动命令。
- 验收通过 pytest、CLI 调用、两份报告和独立 wheel 安装完成。
- V1 仍为只读静态分析，不运行 Docker/hb_mapper/量化，不预测性能、精度或实际 CPU/BPU 分配。
