# Analysis 1.3

Package0.4.0, registry0.3.0, new MatMul/Softmax/Resize packs0.1.0. Conv0.1.0 and six V1.2 packs0.2.0 unchanged. Retains all 1.2 keys. nodes/inspect/trace accept1.0–1.3, resource/candidate commands accept1.1–1.3. shape/shapes require shape_analysis1.0; older reports return an explicit rerun-analyze error, without loading ONNX.

shape_analysis has summary before/after payload-known counts, newly proved Tensor/axis counts, conflict count, passes, budget_exceeded and unknown reason counts. facts has one row per original Tensor: original and ONNX-inferred shape/dtype, canonical final metadata, per-axis status/origin/proof ID, producer and payload_became_known. proofs bind stable node/Tensor IDs, imported opset, previous symbols, precise premises, tiny parameter facts, derivation and engineering limits. tiny_values are typed integer values, distinct from Tensor metadata shape; PROVEN/PARTIAL/UNKNOWN cannot replace unknown elements with guessed values. Unknown origins have bounded first_blocking_sources, visited names and truncation flag. Conflicts retain existing and derived facts, never overwrite concrete metadata, and mark affected covered diagnostics NEEDS_VERIFICATION unless a definite failure has priority.

diagnostic_changes records node before/after status, per-rule actual/status changes and proof IDs; original_static_failures retains complete original failing-rule evidence. Exactly one current diagnostic per node; coverage and four-status counts sum to original node count. Only known metadata refinements affect resource arithmetic. No Tensor/node/edge removal or renaming.

MODEL_ORIGINAL / ONNX_INFERRED / STATIC_DERIVED / UNKNOWN are axis origins; CONFLICT is an explicit Tensor fact status with both premises in conflicts. Symbols alone are not evidence of dynamic input. Public I/O retains the original model contract; no known dimension is replaced. Methods may return partial results under deterministic engineering budgets; all full finished after-counts are concrete integers.

Softmax has static_bpu_path, compiler_configuration_verified=false and actual_runtime_placement=UNKNOWN separately from node status. ONNX opset11 suffix flattening differs from13 axis-only normalization; new semantics do not imply toolchain support. Resize records actual attrs, immutable small numeric sources and exact factor strings. Layout requires independent evidence. MatMul ONNX K/broadcast compatibility is distinct from documented asymmetric BPU pattern and dimensional limits. Every rule retains source/version/column and observed Tensor evidence.
